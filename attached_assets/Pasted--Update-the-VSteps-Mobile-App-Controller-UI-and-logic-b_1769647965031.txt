Developer Tip: How to filter "Steps" from "Movement"
If your current code just looks at if (acceleration > threshold), it will count every little shake. To ensure it "will only be the Steps," you should use a Debounce or a Cooldown in your code.

const STEP_COOLDOWN = 350; // Milliseconds (Humanly impossible to step faster than this)
const STEP_THRESHOLD = 12.0; // Adjust based on pocket tightness
